# 과학 그림 확보

1. 그림이 설명할 관계, 필요한 축·단자·표식·순서, 모바일 폭을 정한다. 교체할 때는 기존 그림과 문단 사이에 어떤 불일치가 있는지 확인한다.
2. 원 논문·리뷰, 공식 명세, 공개 교재, 파일별 출처가 있는 저장소 순으로 원본 페이지를 찾는다. [후보·허가·표기 기준](references/source-selection.md)에 따라 원작자와 파일별 재배포·수정 허가를 확인한다. 허가를 확인할 수 없으면 원문 그림으로 연결한다.
3. 선택한 원본과 필요시 대안 하나를 `experiment/`에서 다룬다. 검색 미리보기 대신 실제 파일을 연다. `scripts/inspect_candidate.py`로 파일과 예상 라벨을 확인하고, SVG는 렌더링, PDF는 `scripts/extract_pdf_page.sh`로 해당 쪽을 추출해 직접 본다. 표시 쪽수와 파일 쪽수를 구분한다.
4. 허용된 발췌·여백 자르기·형식 변환만 필요한 만큼 한다. 축·부호·색의 의미와 예외가 유지되는지 원본과 비교한다. SVG의 viewBox 밖에 남은 요소, 외부 자산 의존, 모바일 가독성도 확인한다. 의미나 필수 표식을 보존할 수 없으면 다른 그림을 찾는다.
5. 도식은 SVG, 곡선·스크린샷은 PNG를 우선한다. 최종 파일은 가까운 주제의 `images/`에 둔다. 여러 분야에서 공유할 때만 `docs/assets/images/`를 쓴다. 외부 이미지 hotlink는 사용하지 않는다.
6. 한국어 대체 텍스트에는 보이는 관계를, 캡션에는 읽어야 할 결과와 저자·원제·그림/쪽·원문 URL/DOI·라이선스와 링크·모든 수정 여부를 적는다. [작성 형식](../../../refs/format.md)에 맞게 연결한 뒤 자료와 캡션을 함께 확인한다. 파일이나 해석 변경에 맞는 검증은 게시 단계에서 한 번 수행한다.
