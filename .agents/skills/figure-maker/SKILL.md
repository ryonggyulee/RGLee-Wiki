# 본문 설명 그림

작성 중인 절에서 독자가 직접 그려 보거나 계산해야 이해되는 관계를 찾는다. 그림으로 답할 질문 하나를 정한다. 본문이나 기존 그림으로 이미 답이 보이면 그대로 둔다.

본문 삽화·개념도·비교 패널·GIF 프레임을 만들 때 OpenAI Images API를 자유롭게 사용한다. 설명할 관계에 따라 API로 그림 전체를 그리거나, 생성한 그림에 SVG나 코드로 라벨·화살표·계산 결과를 얹을 수 있다.

- 구조·연결·비교에서는 독자가 같은 대상을 따라갈 수 있도록 배치한다. 예를 들어 겹치는 분자 조각은 같은 원자가 같은 위치에 오도록 맞춘다.
- 수치와 곡선은 본문의 식이나 원자료로 계산해 그린다. 기호·축·단위와 적용 조건을 본문에 맞춘다.
- 움직임이 설명의 핵심이면 같은 구도에서 단계별 GIF를 만든다. 예를 들어 CNN 합성곱에서는 필터의 가중치를 고정하고, 선택한 입력 영역과 곱의 합이 기록되는 출력 칸을 함께 강조한다. 한눈에 두 단계를 비교하는 편이 쉬우면 정적 패널을 쓴다.

API로 PNG를 만들 때는 도안을 `experiment/` 아래에 두고 [기존 Images API 렌더러](../illustrate-wiki-summary/scripts/render.py)를 사용할 수 있다. 저장소 루트에서 아래처럼 실행하면 생성된 PNG 경로가 출력된다. 도안 경로는 작업에 맞게 바꾼다. [작성 환경과 API 키 설정](../illustrate-wiki-summary/SKILL.md#생성)

```bash
experiment/diagram-venv/bin/python -I .agents/skills/illustrate-wiki-summary/scripts/render.py experiment/그림도안.txt --generate
```

GIF는 API로 만든 기준 그림을 여러 프레임에 재사용하거나 단계별 장면을 생성한 뒤 조립한다. 코드로 각 프레임을 직접 그려도 된다. 프레임 사이에서 시점·축·색의 뜻을 맞추고, 연산을 보여 줄 때는 같은 입력에서 계산한 값으로 각 단계의 상태를 표시한다. 같은 크기의 PNG를 순서대로 준비하면 Pillow가 설치된 환경에서 `python scripts/make_gif.py 연산.gif 01.png 02.png 03.png`로 묶을 수 있다(스킬 디렉터리 기준).

완성본을 열어 연결·라벨·계산값을 대조한다. GIF는 처음·중간·끝의 강조 위치와 재생 속도도 확인한다. 글 옆의 `images/`에 저장하고 [그림 표기](../../../refs/format.md#그림표측정)에 따라 처음 설명하는 문단 곁에 번호를 붙인다. `![한국어 대체 텍스트](images/파일명)`으로 삽입하고, 캡션에는 그림을 멈춰도 알 수 있도록 핵심 관계와 조건을 적는다. API로 만든 그림이나 프레임을 사용하면 캡션에 생성한 부분과 모델을 밝힌다.
