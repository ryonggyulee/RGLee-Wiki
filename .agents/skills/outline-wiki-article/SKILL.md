# 과학 문서 목차 설계

1. 독자가 마지막에 설명하거나 판단할 대상부터 정한다. 기존 문서라면 H1–H3와 각 절의 첫 문단을, 새 글이라면 표준 교재·리뷰의 전개와 위키의 선행 문서를 비교한다.
2. 각 H2 옆에 ‘앞에서 알아야 할 것 → 여기서 새로 알게 되는 것’을 한 줄씩 써 본다. 뒤 절의 정의를 먼저 써야 한다면 정의를 앞으로 옮기거나 선행 문서를 연결한다. 짧은 가정은 해당 식이나 절에 둔다.
3. **주제에 따라 순서를 고른다.** 현상은 원인과 기준 모형에서 관측량·측정·적용 한계로, 계산법은 입력과 근사에서 연산·출력·검증으로, 공정은 반응 원리에서 단계별 표면 변화·측정 결과로 잇는다. 나란한 절에는 같은 질문을 적용하고 조건별 사례는 해당 절 아래에 둔다.
4. 제목만 읽으며 빠진 연결과 중복을 확인한다. ‘개요 → 온도 → PEALD → 특징’에서는 온도가 어느 단계에 작용하는지 알기 어렵다. ALD라면 ‘표면 반응의 포화 → 열 ALD 한 사이클 → 플라즈마를 쓰는 반쪽 반응 → 성장 조건과 측정값’으로 잇고, 한 사이클 아래에 전구체 주입·첫 퍼지·공반응물 주입·둘째 퍼지를 둔다. 표제에는 핵심 명사를, 관계의 설명은 본문에 쓴다.

설계만 요청받으면 목차와 배열 이유를 반환한다. 재배치 요청이면 변경한 절 사이의 연결, 식·그림 참조, 인용 범위를 확인한다. 주장의 의미가 바뀌는 수정은 국소 개정으로 분류한다. 작성 형식은 [공통 기준](../../../refs/format.md)을 따른다.
