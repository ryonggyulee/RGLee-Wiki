# 한국어 윤문

1. 대상 문단과 인접한 정의를 읽는다. 소제목을 바꾸면 전체 제목 목록과 해당 절의 내용을 함께 본다. [용어 색인](../../../refs/terminology.md)에서 표기를 정하고 [작성 형식의 문장 기준](../../../refs/format.md)을 적용한다.
2. 독자가 생략된 대상·비교 기준을 복원해야 하는 문장부터 고친다. 기호를 물리량 이름에 연결하고 명사 사이의 관계를 서술어로 풀어 쓴다. 불확실한 인과관계는 보충하지 않는다. 유형별 [수정 전후 예시](references/sentence-revision-examples.md)는 판단이 어려울 때 사용한다.
3. 원문과 수정문을 다시 읽어 조건·가능성·부정·인용 범위, 수치·단위·식·코드·직접 인용이 보존되는지 확인한다. 의미가 불분명한 대목은 원문을 유지하고 이유를 알린다. 변경량이나 문장 길이를 목표로 삼지 않는다.

검토 요청에는 위치와 제안만 반환한다. 수정 요청에는 대표 수정 전후와 이유를 제시하고 의미 보존 경로로 게시 검사를 진행한다. H1·경로 변경이나 목차 재배치는 해당 요청이 있을 때 담당 스킬에서 처리한다.
