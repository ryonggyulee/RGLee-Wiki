# 과학 문서 작성 형식

## 제목과 링크

- 문서 맨 위의 YAML front matter에 범위와 목적을 담은 한국어 한 문장 `description`을 쓴다. 추가 필드는 사용처가 있을 때 둔다.
- H1 하나를 문서의 정식 제목으로 삼는다. `# MOSFET: Basic operation`처럼 번호 없는 영문 sentence case로 쓰고 약어·고유명의 대소문자를 지킨다.
- 절 제목은 `## 1. 표면 반응의 포화`, `### (1) 전구체 주입`처럼 H3까지 쓴다. 절의 이름과 순서는 [목차 구성](outline.md)을 따른다.
- 선행 개념은 처음 필요한 곳에서 상대 경로로 연결하고 개념명이나 문서명을 링크 문구로 쓴다.

## 정의·수식·코드

- 용어와 물리량은 처음에 정의한다. 식 곁에 기호·단위·각 항의 뜻과 성립 조건을 적고, 근사나 생략한 유도 단계를 밝힌다. 예제에도 같은 가정과 기호를 쓴다.
- 기호·부호·좌표축·지수·정규화 기준을 일관되게 쓴다. 문헌의 규약이 다르면 같은 기준으로 변환한 뒤 비교한다.
- 인라인 식은 `$...$`, 독립 식은 별도 줄의 `$$`로 감싼다. 코드 블록에는 언어를 표시하고, 입력과 실행 조건은 코드 앞에 적는다.

## 그림·표·측정

- 새 과학 문서와 요약 도식을 요청받은 기존 글에는 도입문 뒤에 [요약 그림](../.agents/skills/illustrate-wiki-summary/SKILL.md) 한 장을 둔다. 생성형 이미지는 이 그림에만 쓰고, 측정 곡선·현미경 사진·시뮬레이션 결과는 원자료를 쓴다.
- 요약 그림은 `<figure id="summary-figure" markdown="span">`에 넣고, 캡션은 `요약 그림. …`, 본문 링크는 `[요약 그림](#summary-figure)`으로 쓴다. 본문 그림은 `그림 1`부터 센다.
- 본문 그림은 `<figure markdown="span">`, 캡션은 `<figcaption markdown="1">`에 넣는다. 캡션의 식도 `$...$`로 감싼다. [문헌 그림의 허가와 출처](../.agents/skills/acquire-scientific-images/SKILL.md)를 확인한다.
- 구조·경로·순서는 그림으로 보여 주고, 단자·전류 경로·전기장 방향 또는 측정 구간 중 어디를 읽을지 본문에서 짚는다. 같은 그림은 처음 나온 곳으로 연결한다. 표를 쓰면 앞에 비교 기준을 밝히고 열 이름과 설명을 한국어로 적는다. 작은 화면에서도 읽히는지 확인한다.
- 측정으로 설명하는 현상 뒤에는 다음 블록을 둔다.

```markdown
!!! info "[Measurement]"
    단자 연결, 고정 조건, 주사 변수와 필요한 소자군을 적는다.
    지표를 구할 곡선 구간과 추출식, 단위를 적는다.
```

- 자세한 측정 조건·정규화·회귀 구간·통계량은 `!!! abstract "[Metric]"`, 해석상 주의점은 `!!! warning "[Interpretation Caveat]"`에 보충할 수 있다.

## 인용

주장을 뒷받침하는 문장 바로 뒤에 `[1,2]`처럼 번호를 붙인다. 번호를 매긴 마지막 참고문헌 절에 본문 등장 순서대로 저자, 원제, 학술지·권·쪽·연도, DOI 또는 안정적인 URL을 쓴다. 책은 판·출판사를, 소프트웨어 문서는 버전을 식별한다. 출처 판단과 원문 확인은 [조사 원칙](research-workflow.md)을 따른다.
