# 주장과 근거를 대조하는 방법

## 출처 선택

비자명한 과학적 주장마다 같은 뜻·가정·적용 범위를 직접 뒷받침하는 독립 출처 두 개 이상을 확인한다. 중심 결론, 논쟁적 결과, 수치, 규약에 민감한 관계에서 두 출처로 판단하기 어려우면 근거를 더 찾는다.

| 주장 성격 | 우선 조합 |
| --- | --- |
| 이론의 원래 정의·유도 | 원 논문 + 권위 있는 리뷰 또는 대학원 수준 교재 |
| 현재의 학술적 합의 | 복수의 독립 리뷰 + 필요한 원 논문 |
| 수치·실험 결과 | 원 연구 + 독립 재현 또는 별도 데이터셋의 연구 |
| 소프트웨어의 현재 동작 | 공식 문서·릴리스 자료 + 독립적인 사용 또는 분석 자료 |
| 규약·표준 | 표준 또는 공식 명세 + 해당 분야의 권위 있는 적용 문헌 |

블로그, 검색 요약, 출처 없는 강의 노트와 생성형 AI의 답변은 탐색 단서로만 사용할 수 있으며 최종 근거로 세지 않는다.

## 검증 단위

- 같은 전제와 근거를 쓰는 주장은 묶는다. 원문의 절·식·그림·공식 문서 버전과 실제로 확인한 범위를 남긴다. 사전 지식은 일관성 점검에만 사용한다. 확인하지 않은 수치·서지 정보·인용문·소프트웨어 동작을 지어내지 않는다.
- 미러·프리프린트·출판본이나 같은 데이터를 재인용한 자료는 한 출처이다. 한 연구가 보고한 값은 그 연구의 조건에 귀속한다. 일반적 성능이나 독립 재현을 주장하려면 별도의 근거가 필요하다.
- 단위계, 부호, 좌표, 정규화 및 근사를 맞춘 뒤 비교한다. 예제는 원문에서 전제를 확인하고 유도·대입·단위 변환을 재현할 수 있게 남긴다. 직접 인용은 원문 문구와 문맥까지 대조한다.
- 불일치가 있으면 정의·조건·표본·버전의 차이를 먼저 찾는다. 해결되지 않은 쟁점 자체를 다룰 때는 각 입장의 범위와 근거를 밝힌다. 나머지 미확인 주장은 제외한다. 보존이 필요하면 연구자의 명시적 승인 아래 비공개 초안으로만 둔다.

## 검증된 작업 사례

재사용할 수 있는 방법의 효과를 실제 콘텐츠에서 확인했을 때만 날짜, 대상, 방법, 확인 기준과 한계를 짧게 덧붙인다.

### 2026-07-31 — Licensed Representative Figure Acquisition

- 적용 콘텐츠: MOSFET 대표 누설 전류와 단채널 효과
- 방법: 주요 절의 도입에 필요한 schematic을 먼저 정한 뒤, CC BY-SA 자료는 라이선스·저자·수정 여부를 확인하여 로컬에 저장하고, 재사용 조건이 불명확한 논문 그림은 복제하지 않고 원문의 figure로 연결했다.
- 확인 기준: 네 대표 그림이 hotlink 없이 strict MkDocs 빌드 결과에 포함되고, 각 캡션과 참고문헌에 출처·라이선스·수정 여부가 남는지 검사했다.
- 재사용 조건: 기존 그림이 개념 이해를 실질적으로 돕고 저자와 재사용 조건을 원본 페이지에서 확인할 수 있을 때 사용한다.
- 예외 또는 한계: 공개 라이선스 schematic도 정량 근거로 사용하지 않는다. 물리 주장은 독립적인 교재·원 논문으로 별도 교차검증한다.
